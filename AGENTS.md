# zenith

zenith is an app for coding with agents, part of lsuite. Its window is native Rust with GPUI 0.2 (`crates/zenith-app`); it is a client of zenith's server (`crates/zenith-code`, a LaunchAgent on 127.0.0.1:4747, on Linux a systemd user service written by `zenith-cli setup`; plan: `docs/zenith-code-rust-plan.md`) through `crates/zenith-client` (WebSocket RPC), derives what it shows with `crates/zenith-model`, and acts through the command registry of `crates/zenith-commands` (also `zenith-cli` and `zenith-mcp`; a new action lands there first, then in the window, and `docs/COMMANDS.md` is regenerated: `ZENITH_WRITE_DOCS=1 cargo test -p zenith-commands docs_are_up_to_date`). The web interface (`code/apps/web`, React; a T3 Code fork, see `code/ZENITH.md`) still serves zenith in a browser. Rust code: `cargo clippy --workspace --all-targets`, `cargo test --workspace`, rustfmt (root `rustfmt.toml`). Tests use made-up names; `npm run privacy` must pass. The look is the lsuite design system (`../lsuite/design`, tokens copied in `crates/zenith-app/assets/lsuite-tokens.json`); `cargo test -p zenith-app` checks contrast on every glass tier.
